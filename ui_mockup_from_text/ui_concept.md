# UI Concept - TaskMaster: AI-Powered Project Management

## Purpose
TaskMaster is an AI-powered project management platform that helps developers and teams organize tasks, track progress, and collaborate efficiently through an intelligent and intuitive interface.

## Users
- **Developers:** To create and manage personal tasks, set deadlines, and monitor daily progress toward project goals.
- **Team Leads:** To assign tasks to team members, monitor overall project status, and review completion rates across the team.

## Core Screens
- **Dashboard:** A visual overview of active tasks, progress charts, priority indicators, and upcoming deadlines.
- **Task Board:** A Kanban-style board with columns for To Do, In Progress, and Done to track task flow.
- **Task Creation Form:** An interactive screen where users create tasks with title, description, deadline, priority, and assignee fields.

## Actions
- **Create Task:** Add a new task with all required details and assign it to a team member.
- **Update Status:** Move tasks across board columns to reflect current progress.
- **Filter and Search:** Find tasks by keyword, priority level, status, or assigned team member.
