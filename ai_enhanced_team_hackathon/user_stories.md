# User Stories

1. As a user, I want to upload my resume so that the AI can analyze my current skill set.
2. As a student, I want to select a target job title so that the AI can identify my skill gaps.
3. As a developer, I want to receive a list of recommended online courses so that I can improve my technical skills.
4. As a user, I want to track my learning progress on a dashboard so that I can stay motivated during my career transition.
5. As an applicant, I want the AI to generate a tailored cover letter so that I can increase my chances of getting an interview.
6. As a professional, I want to set a weekly learning goal so that I can manage my time effectively between work and study.
7. As a user, I want to see a visualization of my career path so that I can understand the steps required to reach my goal.
8. As a job seeker, I want to receive daily industry news so that I can stay informed about the latest market trends.
